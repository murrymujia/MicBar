# 轻声键盘

Android 8.0+ 平板和手机使用的小麦克风输入法，支持 arm64-v8a、armeabi-v7a 和 x86_64。

## 下载、更新与切换

[下载最新版轻量版与完整版](https://github.com/murrymujia/MicBar/releases/latest)。平时在远程桌面说话、打字，选 **Lite 轻量版**。两个版本都内置 SenseVoiceSmall 中英混合离线听写、四键语音栏、Rime 拼音和英文键盘，以及共用的本机个人词典。**Full 完整版**额外内置 Qwen2.5-0.5B-Instruct 写作模型和 ARM64 推理组件，可离线校对、改写和翻译。

从 Android 1.21 起，系统会在非计费网络定期检查同版型更新，自动下载差分、校验并在本机准备好安装包。打开首页点「立即安装」并按系统提示确认即可，也可以开启更新就绪通知。更新受设备联网和后台任务调度影响。可在首页关闭自动准备，或随时点「检查更新 / 切换版本」。跨版型或缺少匹配差分时仅在手动选择后下载完整包。安装期间保留现有键盘可延续个人词典与设置。

从 1.20 升到 1.21，在键盘首页点「检查更新 / 切换版本」再选「增量更新」。从 1.17 至 1.19 可使用发布页的小工具 MicBar-Updater.apk。1.16 及更早版本需要先覆盖安装一次新版。

## iPhone 和 iPad

[iOS 预览版源码和使用方式](ios/README.md)。主 App 支持设备端听写、修改和复制，键盘扩展提供基础拼音、英文和符号。适用于 iOS / iPadOS 16 及以上。

## 在 O+ 里使用

1. 打开轻声键盘，在系统中启用并选中轻声键盘。语音输入还需允许麦克风，单独打字无需录音权限。
2. 在 O+ 远控工具栏选「平板键盘」，点 Mac 上的输入框。O+ 远控默认显示麦克风、删除、回车、键盘四个按钮。其他应用默认展开键盘，按键直接输入当前应用。输入框未提供可见光标或被挡住时，展开键盘的工具栏可显示光标前的文字。O+ 中默认提供这行预览，显示当前行，无法读回内容或确认发送后清空预览。原始远程窗口的位置由 O+ 管理。英文立即上屏，拼音选词后上屏。键盘设置中可选「打字先存草稿，确认后填入」。拖动麦克风可以移动整排按钮。轻点麦克风开始听写，再点蓝色声波按钮暂停。
3. 录音时草稿留在内存中。长按键盘键可在原来那行临时展开预览，再长按收起。离线识别按停顿分段，连续讲话会按短段落更新，最后一小段在暂停后补齐。边录边改时，后续短句会在听写位置继续插入。段间停顿默认不加句号，听写草稿填入句末时补中文句号或英文句点；已有标点保留。两个选项可在键盘设置中独立调整。轻点工具栏 ↵ 或在展开键盘后点 ✓ 将草稿填入当前输入框，用工具栏 ↵ 填入后，原位置会显示发送箭头，再点一次发送。可以停下来核对，也可以连点两下。远控中向电脑发送 Enter，最终动作由目标应用决定。长按工具栏 ↵ 则填入并触发该应用的回车操作（可能换行、搜索或发送）。工具栏退格键轻点删一个字符，长按撤销刚填入且仍在光标前的听写；字母键盘上的退格仍可长按连续删除；有选区时先删选区。轻点预览里的词即可选词并展开键盘；长按错词可以保持工具栏收起，再点麦克风重说，首段结果替换选中的文字。没有识别出新文字时，原词保留。直接打字可轻点键盘键。
4. 中文模式用雾凇全拼，点候选或按空格选词，点候选栏中的原始拼写可直接保留字母。点地球键切换拼音和英语，长按打开系统输入法列表。点上档键输入一个大写字母，连点两次锁定大写。左右滑动空格移动当前输入位置。点 ?123 切到当前语言的符号页，左侧翻页键可找到书名号或编程括号。长按字母键盘或符号键盘右下方的句号，从面板里点选常用标点。齿轮打开键盘设置，可调整主题、键盘高度、数字行、字母键底色、按键音和振动。点草稿里的字可以定位光标。
5. 键盘图标可在完整键盘与四键之间切换。折叠后草稿仍在当前编辑会话里。切换应用、退出输入法或切换编辑会话会清空未提交的内容。
6. 在首页打开「贴边悬浮按钮」并允许悬浮窗；使用其他键盘时，点屏幕边缘的按钮，再选轻声键盘即可返回原应用。拖动按钮会吸附到最近的侧边，首页开关可关闭。若需直接上屏，可在首页选择「结束时自动填入」。编辑过的草稿需要点「填入」确认。

## 语音快捷键与手机横屏

打开键盘设置中的「语音工具栏 · 自定义键位」，选择 0–3 个，再点位置指定手机符号或电脑功能键。默认 0 个。选择电脑键位时首次默认 Tab，可另选 Shift+Tab、Esc、方向键等。Tab 会将当前听写填入后发送按键，不额外补句号；是否接受补全取决于远控和编辑器。手机符号在听写时写入草稿，空闲时写入当前应用。

横屏宽度可在键盘设置选择窄、标准、宽。字母区与语音工具栏共用两步回车。第一次确认当前拼音候选、打字或草稿，第二次发送。长按字母区回车可直接执行应用回车。

横屏展开打字键盘后，键盘悬浮在当前应用上方。拖动键盘底部的短横条可以上下左右移动，位置会在本机记住。点悬浮键盘左下角的向下箭头隐藏整个输入法，点输入框可再次调出。键盘图标可折回四键语音栏，在同一输入会话内保留草稿。

横屏可用高度不超过 480dp 时，字母键盘使用四行低矮布局，数字仍可从符号页输入。出现听写内容时草稿在同一排显示，长按键盘键可收起。键盘展开时复用工具栏显示当前输入，受保护字段除外。

竖屏展开简体中文键盘时，输入拼音会把顶部整行切为候选，左右滑动可查看更多。选词后，同一行依当前光标前的文字提供后续词或短句，点一下只补入选中的内容。例如输入「你好」后可接「，请问」，再选「一下」。底行「⋯」可随时切回工具。联想使用本地词表，轻量版和完整版都支持。手机竖屏默认显示四行字母键。字母键高度随可用宽度调整。「?123」可输入数字和符号；需常驻数字行时，可在键盘设置打开「独立数字行」。已手动设置的数字行和键盘高度偏好继续生效。

## 个人词典和离线写作

首页「个人词典」可添加、单条删除或清空词条。默认自动学习主动点选的拼音候选，以及听写草稿中替换并成功填入的词。录音中或暂停后均可改词。删除或放弃草稿、AI 改写不会自动建立替换词条。可在键盘设置关闭「自动学习选词和听写改字」，手动加入的词仍然可用。普通密码和禁止个性化的字段不会调用个人词典或写作功能。常用拼音的邻键拼错、漏字、多字和相邻字母颠倒会出现备选。大写开头或含大写字母的英文标识符可在拼音模式中直接选原拼写；点候选中的拼写加下划线可继续输入 snake_case。

完整版首页的「写作模型」可下载并导入 Qwen3-4B-Instruct-2507 的 Q4_K_M 文件（2.50 GB，来自 Unsloth 的量化版本）。首次导入会验证文件校验和；选择 4B 后在本机处理。手机或平板内存不足时可切回内置 0.5B。

暂停听写后长按麦克风打开离线写作。可处理当前语音草稿、草稿选区或应用回传的选区，每次最多 400 字符。只有点「采用建议」才修改；在同一输入位置可撤销。清理口述模式会检查建议是否保留原词和技术名称，必要时仅删除明确的语气词。其它模式提供校对、缩短、正式、自然、清单和双向中英翻译。远程应用不回传选区时可用本地听写草稿。AI 需 ARM64，在首次使用时从安装包释放约 491 MB 模型到应用私有空间。可取消生成，退出编辑会话会取消任务。短句整理可能漏改或改变语气，采纳前请核对。

## 本地处理

默认离线，通过 sherpa-onnx 运行 SenseVoiceSmall INT8 中英混合听写和 Silero VAD。可选 Android 设备语音服务，其联网与语言能力由系统服务决定。软件包内置 Rime、雾凇中文全拼和 melt_eng 英文词库。使用精简的雾凇方案，原生 Rime 用户库关闭；轻声的个人词典在听写与键盘间共用。打字、编辑草稿、内置听写均无需网络。不保存录音和草稿历史。可选的键盘切换按钮需要悬浮窗权限，使用前台服务在输入时显示。

## 构建

使用 JDK 17 和 Android SDK 35。从 GitHub 克隆后，先运行 `python3 tools/restore-inputs.py --edition lite`，再运行 `./gradlew :app:assembleLiteDebug`。完整版使用 `--edition full` 和 `:app:assembleFullDebug`。恢复脚本从固定的 1.17 发布包提取模型、词库和原生库，从同一发布的 MicBar-build-libs.zip 取回 Java 依赖，并逐文件校验 SHA-256。可用 `--apk` 和 `--libs` 指定已下载的文件。生成待签名安装包时将 Debug 换成 Release。每次正式更新同时提高两版共用的 versionCode 和 versionName，以 v版本号 标签发布同一签名的 MicBar-Lite-版本号.apk 和 MicBar-Full-版本号.apk，对支持的每个起始版本运行 `python3 tools/make-delta.py OLD.apk NEW.apk MicBar-{Lite或Full}-{旧版本}-to-{新版本}.mupd`，将同版型差分连同两个 APK 和更新工具上传完成后，在 GitHub 标为最新稳定版。

第三方来源、版本及许可证见 app/src/main/assets/licenses。Rime 通过上游公开 C API 调用。编译版雾凇词库采用 Prism 4 格式，替换 Rime 版本时须一起验证词库格式并更新本地词库目录版本。远控端需要支持 Android InputConnection.commitText。
